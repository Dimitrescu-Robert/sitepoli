\section*{Problema 2: Parcurgerea Matricei} %
Considerați următoarea funcție C++ concepută pentru a parcurge o matrice cu \texttt{n} linii și \texttt{m} coloane. %
Parcurgerea necesară se deplasează în jos pe prima coloană (de sus în jos), apoi în sus pe a doua coloană (de jos în sus), apoi în jos pe a treia și așa mai departe, creând un model în zig-zag (șarpe) de la stânga la dreapta. %
Completați spațiile libere \texttt{\_\_\_(1)\_\_\_} și \texttt{\_\_\_(2)\_\_\_} pentru a obține parcurgerea corectă. %

\begin{lstlisting}
#include <iostream>
using namespace std;
void iter_mat(int mat[100][100], int n, int m) {
    for (int j = 0; j < m; j++) {
        if (___(1)___) {
            for (int i = 0; i < n; i++) {
                cout << mat[i][j] << " ";
            }
        } else {
            for (___(2)___) {
                cout << mat[i][j] << " ";
            }
        }
    }
}
\end{lstlisting}

\textbf{Variante:} %
\begin{itemize}[label={}]
    \item A) \texttt{(1) j \% 2 == 0} ; \texttt{(2) int i = n - 1; i >= 0; i--} %
    \item B) \texttt{(1) j \% 2 != 0} ; \texttt{(2) int i = n - 1; i >= 0; i--} %
    \item C) \texttt{(1) j \% 2 == 0} ; \texttt{(2) int i = n; i > 0; i--} %
    \item D) \texttt{(1) i \% 2 == 0} ; \texttt{(2) int i = n - 1; i >= 0; i--} %
    \item E) \texttt{(1) j \% 2 != 0} ; \texttt{(2) int i = n; i >= 0; i--} %
    \item F) \texttt{(1) j \% 2 == 0} ; \texttt{(2) int i = 0; i < n; i++} %
\end{itemize}
\textbf{Răspuns corect:} A %

\section*{Problema 3: Arbore Binar Complet cu Valori Fibonacci} %
Considerăm un arbore binar complet de înălțime infinită. %
Nodurile acestuia sunt numerotate cu numere naturale consecutive ($1, 2, 3, \dots$), aplicând o parcurgere pe niveluri (în lățime), de la stânga la dreapta. %
Astfel, rădăcina, situată pe nivelul $0$, primește indexul $1$; descendenții săi de pe nivelul $1$ primesc indecșii $2$ (stânga) și $3$ (dreapta), și așa mai departe. %
În fiecare nod cu indexul $i$ ($i \ge 1$) este stocată o valoare egală cu al $i$-lea termen din șirul lui Fibonacci, șir definit astfel: %
\[
    F_1 = 1, \quad F_2 = 1, \quad F_n = F_{n-1} + F_{n-2} \quad \text{pentru orice } n \ge 3.
\]

\textbf{Care este expresia matematică corectă ce reprezintă suma valorilor stocate în toate nodurile de pe un nivel oarecare $k$ ($k \ge 1$)?} %

\begin{itemize}[label={}]
    \item A) $F_{2^{k+1}} - F_{2^k}$ %
    \item B) $F_{2^{k+1}+1} - F_{2^k+1}$ %
    \item C) $F_{2^{k+1}-1} - F_{2^k-1}$ %
    \item D) $F_{2^{k+1}+2} - F_{2^k+2}$ %
    \item E) $F_{2^{k+1}} + F_{2^k}$ %
    \item F) $F_{2^{k-1}} \cdot F_{2^k}$ %
\end{itemize}
\textbf{Răspuns corect:} B %

\section*{Problema 4: Complexitate Matrice de Adiacență pentru un Arbore} %
Fie matricea de adiacență a unui arbore cu $V$ noduri. %
Care este complexitatea de timp pentru a afla numărul de muchii și, respectiv, a identifica toate nodurile frunză? %
\begin{itemize}[label={}]
    \item a) Muchii: $O(1)$, Frunze: $O(V^2)$ %
    \item b) Muchii: $O(V^2)$, Frunze: $O(V^2)$ %
    \item c) Muchii: $O(V)$, Frunze: $O(V)$ %
    \item d) Muchii: $O(1)$, Frunze: $O(V)$ %
    \item e) Muchii: $O(V^2)$, Frunze: $O(1)$ %
    \item f) Muchii: $O(\log V)$, Frunze: $O(V \log V)$ %
\end{itemize}
\textbf{Răspuns corect:} a %

\section*{Problema 6: Divide et Impera cu modificare In-Place} %
\textbf{[Dificultate: 9/10]} %

Ce va afișa următorul program C++ la rulare? %

\begin{lstlisting}
#include <iostream>
using namespace std;

int f(int a[], int st, int dr) {
    if (st == dr) return a[st];
    
    int m = (st + dr) / 2;
    int x = f(a, st, m);
    int y = f(a, m + 1, dr);

    if (x > y) {
        a[m] = y;
        return x;
    } else {
        a[m + 1] = x;
        return y;
    }
}

int main() {
    int v[] = {8, 2, 5, 3, 7, 9};
    cout << f(v, 0, 5) << "\n";
    
    for (int i = 0; i < 6; i++) {
        cout << v[i] << " ";
    }
    return 0;
}
\end{lstlisting}

\textbf{Variante:} %
\begin{itemize}[label={}]
    \item A) \texttt{9} \\ \texttt{2 5 5 8 3 7} %
    \item B) \texttt{9} \\ \texttt{5 2 5 8 7 3} %
    \item C) \texttt{8} \\ \texttt{2 5 8 5 3 7} %
    \item D) \texttt{9} \\ \texttt{2 2 5 8 3 7} %
    \item E) \texttt{9} \\ \texttt{8 5 5 2 3 7} %
\end{itemize}
\textbf{Răspuns corect:} A %

\section*{Problema 8: Structuri și Transmiterea Parametrilor} %
\textbf{[Dificultate: 7.5/10]} %

Ce va afișa următorul program C++ la rulare? %

\begin{lstlisting}
#include <iostream>
using namespace std;

struct Punct {
    int x, y;
};

void transforma(Punct &A, Punct B) {
    A.x = A.x + B.x;
    B.y = A.y + B.y;
    A.y = B.y - A.x;
}

int main() {
    Punct p1 = {3, 5};
    Punct p2 = {2, 4};
    
    transforma(p1, p2);
    
    cout << p1.x << " " << p1.y << " " << p2.x << " " << p2.y;
    return 0;
}
\end{lstlisting}

\textbf{Variante:} %
\begin{itemize}[label={}]
    \item A) \texttt{5 4 2 4} %
    \item B) \texttt{5 4 5 9} %
    \item C) \texttt{5 9 2 4} %
    \item D) \texttt{5 -1 2 4} %
    \item E) \texttt{5 4 2 9} %
\end{itemize}
\textbf{Răspuns corect:} A %
